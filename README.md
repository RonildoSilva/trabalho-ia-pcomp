# Trabalho de Inteligência Artificial: classificação e regressão

> Dois notebooks comparando algoritmos de classificação e de regressão do scikit-learn em conjuntos de dados públicos, com validação cruzada e gráficos de desempenho.

![status](https://img.shields.io/badge/status-concluído-success) ![python](https://img.shields.io/badge/Python-3-blue) ![sklearn](https://img.shields.io/badge/scikit--learn-modelos-orange)

## Sobre
Trabalho da disciplina de Inteligência Artificial da pós-graduação (agosto de 2020). `1. Classificação.ipynb` compara classificadores (árvores, k-NN, SVM, ensembles) por acurácia e matriz de confusão; `2. Regressão.ipynb` compara regressores por erro médio. Os dados usados estão em `datasets/`.

## Como executar
```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter && jupyter notebook
```
